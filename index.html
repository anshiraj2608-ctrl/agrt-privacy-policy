AGRT Privacy Policy

Product: Automatic Group RT (AGRT)

Last Updated: November 8, 2026

1. Introduction

Automatic Group RT (AGRT) is a browser extension designed to help authorized users manage retweet workflows on supported X (formerly Twitter) pages. This policy explains how the extension handles information.

2. Information We Handle

Depending on the features used, AGRT may process:

  • License keys and license status.
  • X username or handle.
  • Device public key and browser information.
  • Authentication session tokens.
  • Browser and extension version information.
  • Limited X chat-cache content needed for supported link-related features.

3. How Information Is Used

Information is used for license verification, device registration, account management, authentication, access control, security and extension functionality.

4. Data Sharing

License-related information may be transmitted to the AGRT Google Apps Script licensing service. The extension may also communicate with X-related services, including t.co, for supported functionality.

We do not sell personal information or use it for advertising.

5. Local Storage and Processing

Some settings, session information and supported chat-cache data may be processed or stored locally on the user's device.

6. Data Security and Retention

AGRT uses license verification, device controls and session management to help protect access. License and security records may be retained for administrative and operational purposes.

7. User Requests

For privacy questions or requests concerning information handled by AGRT, contact us using the email below.

8. Policy Changes

This policy may be updated when AGRT functionality or data practices change. Updates will be published on this page.
